ProviderRuntime仍为唯一生命周期所有者。dispose立即使实例不可用；start在配置初始化和注册表初始化两个await边界核对同一实例的disposed状态，关闭后拒绝启动，不复活注册表。node装配处仅在实例仍存活时记录就绪/初始化失败；真实配置失败在活实例上继续报告。公开只读isDisposed供装配观察，不复制关闭状态，不屏蔽任务执行错误。并发start继续共用同一promise，失败仍允许既有重试，dispose幂等。

```text
start → 配置初始化 → 检查存活 → 注册表初始化 → 检查存活 → 就绪
                  ↑                         ↑
dispose → 同一实例disposed=true → 拒绝迟到完成 → 装配忽略关闭后的通知
```
