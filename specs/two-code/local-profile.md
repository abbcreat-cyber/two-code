# 本地用户名与侧栏菜单

- 底部头像菜单移除升级、连接使用和账号退出项，保留语言、主题、界面模式、缩放、使用统计。设置及手机远控入口不变。
- 菜单首项为“修改用户名”；底部显示本机昵称，默认 Two Code，使用产品飞船图标，不展示账号套餐或虚假连接状态。
- 弹窗按参考图呈现产品图标、“你的名字”、本地保存说明、用户名及 24 字符计数、取消和保存。支持中英文界面。
- 单一存储所有者为 UI 本地昵称 hook；使用独立 localStorage key，不提交到服务端，不修改任何模型身份或账号资料。同一窗口同步通知订阅者，其他窗口通过 storage 事件更新。
- 保存去除首尾空白，长度按 Unicode 码点计数，必须为 1 至 24 字符。失败保留输入并显示本地化错误；取消、关闭、Esc 不写入。中文输入法组合阶段 Enter 不提交。
- 验收：菜单无旧入口、默认昵称、修改立即显示、刷新持久化、取消和非法输入不覆盖、失败可见、浅深主题和键盘焦点正常。
- 自动引导被跳过时不得注册为可见状态，也不得拦截昵称弹窗的 Esc；显式打开引导仍沿用原流程。
