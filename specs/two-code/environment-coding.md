# 多环境代码协作验收

固定 Step Plan 主手、Claude DeepSeek 副手。通过 ITwoCodeService 创建隔离 QA 会话；并发执行视觉小任务、浏览器三阶段连续开发、Android 中任务和 VirtualBox 只读代码任务。模型负责代码和原生 PowerShell 验证，验收器持有固定测试、实际执行账本和生命周期。禁止改用户项目、操纵物理输入、操作已有 Android 设备或启动业务虚拟机。

视觉任务由两角色读取像素参考图，再修改 HTML，真实浏览器截图与几何断言验收。浏览器任务连续实现便签 CRUD、刷新持久化和筛选、损坏存储恢复和文本安全；模型编写 Playwright 交互脚本，验收器也独立验证页面行为。Android 使用新建无窗口 AVD，通过 adb 实际往返读写临时文本、读取设备信息与截屏。VirtualBox 仅通过 showvminfo 读取指定 VM，验证解析代码与实际状态；不把只读核验冒充客户机内开发或启动验收。

每阶段最多一次追加修复轮，300 秒截止。同一任务阶段间必须保留主副手 session；每阶段必须交接并有副手报告；固定测试不得变化；原生执行回执数量必须对应独立账本。代码错误、环境不可用与协调器缺陷分别记录，completed 不代表验收通过。

```text
验收器拥有临时环境/固定测试/账本
  → 主手 → 同一副手实现 → 原生命令 → 浏览器/adb/只读VBox
  → 主手看图或审查 → 独立断言 → 精简报告 → dispose → 清理
```

结束或失败均取消本轮尚在运行的会话并释放 services，结束仅本轮 emulator 和无头浏览器。报告放 D:/Apps/TwoCode/reports；删除前校验 QA 根目录及唯一所有权标记。原生会话只能按已记录的精确 ID 和 QA 工作区目录清理，不遍历删除用户任务。历史测试仅按明确列举且已确认归属的目录清理。无法确认归属或未退出的资源保留并报告，不强删。

## 原生执行清单权限

真实 Android/浏览器任务观察到 Step 的 task_create 被归入未知工具，编辑模式出现无必要授权。已核实本机 Step 原生接口文档：task_create/task_update/task_get/task_list 只维护当前原生会话的执行清单，依赖不调度工作；与启动代理的 Task/Agent 不同。清单状态仍由原生底座唯一持有，Two Code 只透传工具调用与现有历史事件，不增设第二套计划。

四种权限模式及两种角色均允许这四个精确工具名，与已有 TodoWrite 一致；副手的 Task/Agent 递归分派限制保持优先，未知 task\_\* 工具不得按前缀自动放行。验证四工具、所有权限模式以及既有递归分派限制，并用 Step Plan/Claude DeepSeek 做一次实际清单创建、交接、验证和完成更新。
