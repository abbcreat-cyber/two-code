# 双模型会话分叉

用户要求打通原前端叉子按钮。分叉是截至已完成一轮的两个原生会话分支，不是把可见聊天摘要重新发给空模型。源任务/文件不回滚，新分支共享工作区但主副手会话身份独立；分叉本身不调用模型。

Coordinator拥有准入与幂等，fork({taskId,atSeq,requestId})复用源任务配置锁及执行租约，源运行中拒绝；同requestId返回同一目标任务，重启后仍成立。只允许没有错误/取消的已完成回答边界。事件复制到该轮结束，清空权限、请求编号与本分支用量，保存来源。前端复用原回答动作栏的onFork并导航新任务，发送仍走原submit。

适配层读原生记录的时间戳定位结束边界：Two Code从未允许同任务跨脚手架续接，所以当前session覆盖该角色历史；不能找到有效原生边界时明确失败，不复制未来上下文。Claude按原生uuid调用SDK forkSession(upToMessageId)。Step/Pi仅处理验证过的v3树状JSONL，沿目标entry的parentId链复制原生条目，以新session header和新文件加载；保留原生工具/压缩记录，不合成模型对话。未派工过的副手仍为空会话。ZCode原生会话协议本轮暂不适配，不能悄悄退化为摘要克隆。

```text
原回答叉子 → UI请求ID → Coordinator源租约 → 两角色原生分支
                                              ↓
                           新任务/独立会话ID → 持久化 → 原列表/新窗格
```
