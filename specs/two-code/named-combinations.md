# 可命名的AI组合

用户希望保存多套主副手搭配、重命名并快速选用。每套组合包含主/副手底座、渠道、模型、思考档位、是否启用副手、权限模式。选择组合只复制配置到当前草稿/空闲任务，不自动改全局默认；“设为默认”只影响之后的新任务。已有原生会话不能跨底座切换，继续沿用现有准入规则。

按用户最新要求：移除“ZCode原生模式”入口和单/双角色分段开关，工具栏统一为“组合 / 主手 / 副手”。副手下拉第一项为“无”，映射既有dual=false，执行时不初始化副手、不提供派工工具；选具体模型恢复dual=true。内部继续使用兼容字段，不把“无”当作假的模型ID。副手关闭时保留已有原生上下文，应用单模型组合不能替换这份休眠上下文；以后显式启用时仍遵守同底座续接规则。单模型组合与双模型组合共用10套名额。

JsonPreferences继续是唯一默认设置所有者，preferences.json保留旧版顶层配置，并在同一原子文件中新增combinations/defaultCombinationId/revision。旧默认无损映射为第一套“默认组合”。保存、改名、删除、设默认共用既有跨进程锁；revision防止不同窗口覆盖；至少保留一套、最多10套，名称1–40字符且不重名。第11套明确提示“已保存10套组合，请先删除多余的组合”，不落盘且保留填写的名字供删除后继续保存。更新默认组合同步更新新任务默认配置，删除默认组合时确认后采用列表中下一套。组合不含API密钥。

```text
原组合弹层 → hook → JsonPreferences锁+revision → 单次原子写入
                        ↓                              ↓
                  当前任务configure             组合变更事件/默认值
                        ↓                              ↓
                    原会话续接                       下一新任务
```

视觉：复用应用已有字体、text-ui-*和语义色，不引入新字体。石墨底（约#292929）、柔白主字（#e4e4e7）、灰色副字（#94949b）、细分隔线（#414147），选中行仅用现有bg-selected。名字一行，主副搭配一行细字；默认标签与当前选中分开。辨识点是紧凑的“双角色配对行”，不用大卡片、渐变或多一排工具栏。

```text
AI 组合                           ＋
✓ 日常协作                 默认   ···
  主 Step-5订阅  ·  副 DeepSeek
  快速处理                        ···
  主 …           ·  副 …
（单模型组合显示“副 无”，不再增加模式切换区）
```

行尾菜单提供重命名、用当前配置更新、设为默认、删除；增改在弹层内完成，不跳设置页。键盘可聚焦每个操作，错误保留输入，保存状态可见。真实验收覆盖三套组合、选择后实际模型配置、默认新任务、改名与重开、陈旧revision拒绝、默认删除及已有会话约束；用一项小任务验证选中的Step Plan/Claude DeepSeek组合仍可真实派工。

组合编辑表单显式停止submit事件传播，避免React Portal将保存/改名事件传入外层聊天表单，误发用户尚未发送的草稿。验收需带着非空草稿保存并确认草稿及任务数量都不变。
