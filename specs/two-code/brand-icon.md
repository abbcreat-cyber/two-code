# Two Code 星海双引擎图标

## 产品规则

使用用户确认的星海双引擎生成图作为应用标志。桌面快捷方式、可执行文件、任务栏、安装器、关于窗口、欢迎引导、侧栏、设置页以及 React 加载前后的首屏均使用同一品牌图。模型提供商的商标不替换。

圆角图标外部必须为真实透明 alpha；保留圆角方块内的星空。不允许将外围黑底、假透明棋盘格或矩形底色打入资源；UI 外壳不再补画黑色底板。各 PNG/ICO 帧需检查四角 alpha=0。

## 资源所有者与生成

`public/logo/two-code-master.png` 是唯一原图，`scripts/two-code-icons.mjs` 派生 UI PNG、多尺寸 ICO、ICNS、Linux PNG 和网页 favicon。不重新生成或改变已确认的设计；仅做尺寸和容器格式转换。HTML 首屏直接引用同一 UI 资源，由 Vite 管理打包路径。

## 边界与验收

- 保留现有启动就绪事件、动画结束和无动画偏好；不改变启动等待逻辑。
- 小尺寸图标保持完整构图；加载页避免双重图标内边距。
- 源码中应用身份入口不再引用旧 ZCode 路径或图形。
- 生成资源可重复，ICO 包含 16 至 256 像素帧；发布包包含新图与新 exe 图标。
- 后台启动隔离的发布包检查启动屏和主界面；生产会话不强制终止。
- 桌面快捷方式指向新发布包及独立版本 ICO，避免复用旧图标缓存。
